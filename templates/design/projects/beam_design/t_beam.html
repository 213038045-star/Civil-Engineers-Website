Formula Reference

Every equation used above, in the order applied
01 · Demand from load
Factored moment from uniform load
Mu = wu L² / n
n depends on support condition (8 = simply supported, 10–16 = continuous cases per ACI 318-19 6.5.2, 2 = cantilever). L in ft, wu in kip/ft.
02 · ACI 318-19 Table 6.3.2.1
Effective flange width
bf = min( L/4,  bw+16hf,  bw+savg )
Interior beams. Isolated T-beams instead use bf ≤ 4bw with additional flange-thickness limits.
03 · Nominal flexural strength
Required steel — rectangular assumption
Mu/φ = Asfyd − (Asfy)² / (1.7f′cb)
Solved as a quadratic in As; the smaller positive root is used. b = bf for the initial check.
04 · Whitney stress block
Compression block depth
a = Asfy / (0.85f′cb)
If a ≤ hf, the section behaves as rectangular and the Step 03 result governs directly.
05 · T-beam split (if a > hf)
Flange overhang contribution
Asf = 0.85f′c(bf−bw)hf / fy
ΔMnf = 0.85f′c(bf−bw)hf(d−hf/2) is the moment this steel resists; the remainder is passed to Step 03 with b = bw.
06 · ACI 318-19 22.2.2.4.3
β1 factor
β1 = 0.85 (f′c ≤ 4 ksi)  →  0.65 (f′c ≥ 8 ksi), linear between
Relates the neutral-axis depth c to the stress-block depth a: c = a/β1.
07 · ACI 318-19 21.2.2
Net tensile strain & ductility class
εt = 0.003 · (dt − c) / c
εt ≥ 0.005: tension-controlled, φ=0.90. 0.002–0.005: transition. <0.002: compression-controlled — not permitted for flexural members.
08 · ACI 318-19 9.6.1.2
Minimum flexural reinforcement
As,min = max( 3√f′c/fy · bwd ,  200/fy · bwd )
f′c, fy in psi. Based on web width bw — applies to positive-moment (flange in compression) sections.
09 · ACI 318-19 25.2.1
Bar clear spacing (fit check)
s = [ bw − 2(cover+dtie) − n·db ] / (n−1)
Must satisfy s ≥ max(db, 1 in, (4/3)dagg) — here assumed dagg = 3/4 in, so the floor is 1 in. n is forced to at least 2 bars for redundancy.
Calculation aid only — not a substitute for review and stamping by a licensed engineer. Assumes positive moment (flange in compression), single layer of tension steel (dt = d), no compression reinforcement. Shear, deflection, and negative-moment design are not included.
