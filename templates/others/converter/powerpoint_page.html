Numbers are inserted as live PowerPoint fields (bottom-right of each slide), so they'll stay correct if you reorder or add slides later in PowerPoint. A custom start number is written using PowerPoint's own "first slide number" setting — PowerPoint desktop honors it; some other viewers (Google Slides, LibreOffice) may still display the true slide position instead.
