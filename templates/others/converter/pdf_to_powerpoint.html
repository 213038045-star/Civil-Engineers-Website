Important: Hybrid mode keeps a rendered PDF page as the background and places extracted text over it. This preserves photographs, drawings, tables, charts and unusual PDF artwork. Because the original text is still present in the background, some PDFs can show slightly duplicated text. Use Editable text only when you want the cleanest editable result.
