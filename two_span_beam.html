Load — two-way slab tributary (both sides)
Each side panel delivers a trapezoidal load to this beam via 45° yield lines (triangular when S = Lspan): peak w₀ = qᵤ·S/2, ramps of length S/2 at each end, plateau w₀ over the middle. This is converted to an equivalent uniform load for design — wM = w₀(1 − m²/3) for moment and wV = w₀(1 − m/2) for shear, with m = S/Lspan ≤ 1 — then combined per span (S1-side + S2-side + self-weight). The continuous beam is solved by the three-moment theorem generalized for two different per-span uniform loads, which reduces to the textbook single-w case when w1 = w2. Clear the override field to use the trapezoidal transfer; entering a value bypasses it with one shared uniform load (legacy tributary-width behavior) on both spans.
