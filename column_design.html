⚠ This tool gives preliminary strength design (USD) results for axial + uniaxial bending using ACI 318 provisions as adopted by BNBC 2020 Part 6 (Reinforced Concrete Structures). Axial load is built up from just two full column-to-column spans (tributary area = (S₁/2)×(S₂/2), beam length = S₁/2+S₂/2, per standard interior-column tributary convention): slab self-weight, floor finish, beam self-weight (auto from beam section), optional wall load, and live load, accumulated over the number of stories above the column, factored per §5.3.1 (1.2D + 1.6L). It assumes uniform floor-to-floor loads, no live-load reduction, and no lateral (wind/seismic) load — enter uniaxial moment separately. It does not generate a full P-M interaction diagram or biaxial check. Final column sizing, detailing, and construction drawings must be verified and sealed by a licensed structural engineer.

Load takedown, one story: TA = (S1/2)×(S2/2); beam trib. length = S1/2+S2/2; slab self wt (psf) = γc·t/12; beam load = [(bw·hb/144)·γc]·trib. length; wall load = [wall γ·(twall/12)·hwall]·trib. length; column self wt = (b·h/144)·γc·story ht
Total load in one story: DL/story = slab self wt + floor finish + beam load + column self wt + wall load; LL/story = LL(psf)·TA
Total over N stories: ΣDL = DL/story × N; ΣLL = LL/story × N
Load factoring (BNBC 6.2.3 / ACI 318-19 §5.3.1): Pu = 1.2ΣDL + 1.6ΣLL (gravity-only; add wind/seismic combos separately for Mu if governing)
Axial capacity (BNBC 6.8 / ACI 318-19 §22.4.2): φPn,max = α·φ·[0.85f'c(Ag−Ast) + fyAst]; α=0.80, φ=0.65 (tied); α=0.85, φ=0.75 (spiral)
Reinforcement limits (§10.6.1.1): 0.01 ≤ Ast/Ag ≤ 0.08; min. 4 bars (tied) / 6 bars (spiral)
Minimum moment (§6.6.4.5.4): M2,min = Pu(0.6 + 0.03h), h in inches
Slenderness (§6.2.5): may be neglected if kLu/r ≤ 34−12(M1/M2) ≤ 40 (braced) or ≤ 22 (unbraced) — shown here as a simplified conservative check only
Tie spacing, middle zone (§25.7.2 / BNBC 8.1.9): s ≤ min(16db,long, 48db,tie, least column dimension)
Tie spacing, end zone — OMF columns (§18.3.4 / BNBC Part 6 Ch.8): over length lo = max(clear height/6, max cross-section dim., 18 in) from each joint face, so ≤ min(8db,long, 24db,tie, 0.5·least dim., 12 in); first tie ≤ so/2 from the joint face
Tie bar: #3 min. for long. bars ≤#10, #4 min. for #11/#14/#18 or bundled bars
This load takedown assumes uniform per-floor loads and no live-load reduction — a simplification for preliminary sizing only.
